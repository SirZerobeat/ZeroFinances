## 🐛 TROUBLESHOOTING

### Issue: Backend won't start
**Solution:**
- Verify Python 3.11+: `python --version`
- Verify PostgreSQL: `psql -U postgres -d zerofinances`
- Check .env file exists and DATABASE_URL is correct
- Reinstall: `pip install -r requirements.txt`

### Issue: No response from Gemini
**Solution:**
- Verify GEMINI_API_KEY in .env
- Get key from: https://makersuite.google.com/app/apikey
- Check API key is not expired/revoked
- Verify rate limit: 15 requests/minute

### Issue: "Authorization header not found"
**Solution:**
- Include in request: `Authorization: bearer TOKEN`
- Replace TOKEN with actual token from login
- Capital B in "Bearer"
- Verify token is not expired (30 min default)

### Issue: Frontend won't connect to backend
**Solution:**
- Verify backend running: http://localhost:8000/api/v1/health
- Check frontend API_BASE_URL in src/api/client.ts
- Ensure CORS is enabled (it is by default)
- Check browser console for error details
