🚀 QUICK START (3 STEPS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Get Gemini API Key
  → https://makersuite.google.com/app/apikey
  → Click "Create API Key" and copy

STEP 2: Start Backend (Terminal 1)
  cd ZeroFinancesBack
  copy .env.template .env
  notepad .env (add GEMINI_API_KEY)
  python -m venv venv
  venv\Scripts\activate
  pip install -r requirements.txt
  uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

STEP 3: Start Frontend (Terminal 2)
  cd ZeroFinancesFront
  npm install
  npm start
  (press 'w' for web)

RESULT: Backend on :8000, Frontend on :19006

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🧪 TEST IT (Pick one method)

METHOD 1: Swagger UI (EASIEST!)
  1. Open: http://localhost:8000/docs
  2. Click: POST /api/v1/auth/login
  3. Try it out
  4. Paste: {"email":"admin@test.com","password":"admin123"}
  5. Execute
  6. Copy the token
  7. Scroll to POST /api/v1/chat
  8. Paste token in Authorization header
  9. Paste: {"message":"Hola Zero"}
  10. Execute - See real Gemini AI response!

METHOD 2: cURL
  TOKEN=$(curl -s -X POST http://localhost:8000/api/v1/auth/login \
    -H "Content-Type: application/json" \
    -d '{"email":"admin@test.com","password":"admin123"}' \
    | grep -o '"token":"[^"]*"' | cut -d'"' -f4)

  curl -X POST http://localhost:8000/api/v1/chat \
    -H "Authorization: bearer $TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"message":"Hola Zero, cuéntame un chiste"}'

METHOD 3: Frontend App
  Open http://localhost:19006
  Login: admin@test.com / admin123
  Go to Chat tab
  Type: "Hola"
  See: Real Gemini response!
